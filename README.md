## CLI Task Tracker
About the Project

This is a simple Command Line Task Tracker made using Python.
You can add tasks, update tasks, change status, and delete tasks.
All tasks are stored in a JSON file, so your data is saved even after closing the program.

**This project helped me learn:**

Python basics
File handling
JSON
Lists and dictionaries
Functions

## Features

The application can:

View tasks
Add a task
Update task title
Change task status (pending / in-progress / completed)
Delete task
Save tasks in JSON file

## How to Run the Project
Install Python
Open terminal
Go to project folder
Run: python main.py
